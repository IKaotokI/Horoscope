# ดวงสามศาสตร์ (ไทย · จีน · สากล)

เว็บดูดวงที่คำนวณทุกอย่างในเบราว์เซอร์ บังคับกรอกแค่วันเกิด ส่วนเวลา จังหวัด และเพศกำเนิดเป็นตัวเลือกที่ช่วยปลดล็อกผลเพิ่ม ไม่มีเซิร์ฟเวอร์ ไม่เก็บข้อมูล และไม่ต้องสมัครสมาชิก
สเปกและกฎทั้งหมดอยู่ใน [CLAUDE.md](CLAUDE.md)

## เริ่มใช้งาน

```bash
npm install
npm run dev        # เปิดเซิร์ฟเวอร์สำหรับพัฒนา
npm test           # unit test (vitest)
npm run build      # typecheck + build เป็นไฟล์ static ใน dist/
```

```

  thai/             ขอบวันไทย, ทักษา/สี/มหาทักษา, จันทรคติ, เลข 7 ตัว, นักษัตรไทย
  chinese/          ก้านกิ่ง/ปีชง, ปาจื้อ + 大運, Kua, ปฏิทินจีนวันนี้
  western/          ephemeris (astronomy-engine + Lahiri), ราศี/ดวงชะตา/ฤกษ์ 27,
                    เลขศาสตร์, ทาโรต์, ไบโอริทึม, Tzolk'in
src/data/           ตารางจันทรคติไทย (สร้างจาก pythaidate), พิกัดจังหวัด
src/ui/             หน้าเว็บ (vanilla TS), กราฟิก SVG, กาแล็กซี canvas (galaxy.ts)

scripts/            สคริปต์สร้างตารางจันทรคติ
tests/              unit test เทียบกับค่าตรวจใน CLAUDE.md และไลบรารี
```

## สิ่งที่ทำแล้ว (MVP + ส่วนที่ปลดล็อกได้)

| ศาสตร์ | ต้องการ |
|---|---|
| วันเกิดไทย, ทักษา 8 ภูมิ (ผัง 3×3), สีมงคล/กาลกิณี, มหาทักษา | วันเกิด (เวลาช่วยแยกพุธกลางวัน/คืน) |
| ราศีไทย (นิรายนะ ลาหิรี), ดวงชะตาวงล้อเลขไทย | วันเกิด (ลัคนาต้องมีเวลาและจังหวัด) |
| จันทรคติไทย, เลข 7 ตัว 4 ฐาน, นักษัตรไทย 3 ธรรมเนียม | วันเกิด |
| ฤกษ์ 27 | วันเกิด (ได้ค่าเดียวพร้อมบาทเมื่อมีเวลา) |
| นักษัตรจีน (ลิบชุน/ตรุษจีน), ปีชงแบบไทย, คู่สัมพันธ์ | วันเกิด |
| ปาจื้อ 3 เสา / 4 เสา, สมดุลธาตุ, true solar time, 早子/晚子 | วันเกิด (+ เวลา, จังหวัด) |
| Kua, 大運 | เพศกำเนิด (Kua แสดงทั้งสองแบบถ้าไม่ระบุ) |
| ราศีสากล, จันทร์ราศี, ASC, วงล้อ 12 ราศี | วันเกิด (+ เวลา, จังหวัด) |
| Life Path / Birthday / Personal Year, ไพ่ประจำวันเกิด/ปี, ไพ่รายวัน, ไบโอริทึม, Tzolk'in | วันเกิด |
| ปฏิทินจีนวันนี้ (宜忌 冲煞 建除) | – |

หน้าแรกเป็นธีม Galaxy: ฟอร์มเรียงแนวตั้งชิดซ้าย (เวลาเกิดเลือกเป็นชั่วโมง คำนวณที่ HH:30) ส่วนที่เหลือเป็นกาแล็กซีหมุนช้าๆ ทวนเข็ม มีประกายดาว 11 ดวงแทนแต่ละศาสตร์ ชี้เมาส์เพื่อดูชื่อ ดาวจะเปล่งแสงพร้อมเงาสัญลักษณ์ของศาสตร์นั้นเมื่อกรอกข้อมูลครบตามเงื่อนไข

ผลลัพธ์ทุกการ์ดแสดง "ธรรมเนียมที่ใช้" และสลับธรรมเนียมได้ในที่ที่มีหลายแบบ ข้อมูลที่ยังติด **[ยังไม่ยืนยัน]** ใน CLAUDE.md จะมีป้าย "ยังไม่ยืนยัน" กำกับในหน้าเว็บ ต้องตรวจก่อนเปิดตัวจริง

## ที่ตั้งใจยังไม่ทำ

- เลข 7 ตัวฐาน 5–9, อนุทักษา, ชื่อฤกษ์ภาษาไทย/9 หมู่ฤกษ์, เกตุไทย, ตารางทิศดี/ร้ายของ Kua, ผังดวงสี่เหลี่ยม: ยังไม่มีแหล่งยืนยัน
- สุริยยาตร์, 紫微斗數, ชั้น AI: phase 2
- ภาพไพ่ RWS 1909: รอตรวจลิขสิทธิ์ในไทย ตอนนี้ใช้การ์ดที่วาดเอง
- ไม่ใช้ Swiss Ephemeris (AGPL)

## การตรวจสอบที่ทำแล้ว

- ตารางจันทรคติจาก pythaidate ตรงกับวันพระใหญ่ในปฏิทินหลวง (วิสาขบูชา 2568, มาฆบูชา 2569 ที่เป็นปีอธิกมาส)
- ปาจื้อตัวอย่างที่คำนวณมือใน CLAUDE.md (15 ก.ค. 1990 12:00 → 庚午 癸未 辛巳 甲午) ตรงกับ lunar-javascript, เสาวันตรงกับไลบรารีทุกวันตลอด 2 ปี และเสาเดือนตรงกับสูตรลองจิจูดดวงอาทิตย์ + 五虎遁
- ชื่อเมธอด `getEightChar`, `setSect`, `getYun` ของ lunar-javascript มีจริง (อ่านจากซอร์ส 1.7.7)
- ลัคนาจากสูตรใน CLAUDE.md อยู่บนขอบฟ้าทิศตะวันออกจริงเมื่อตรวจด้วย astronomy-engine
