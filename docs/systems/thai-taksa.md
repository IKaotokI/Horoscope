# ทักษา 8 ภูมิ · สีมงคล/กาลกิณี

> หมวด: ไทย · สถานะ: **MVP** · ต้องใช้แค่วันเกิด (เวลาช่วยแยกพุธกลางวัน/คืน)
> กลับไปที่ [CLAUDE.md](../../CLAUDE.md) · เกี่ยวข้อง: [วันเกิด/สีประจำวัน](thai-birth-day.md), [มหาทักษา](thai-mahataksa.md)

## ภาพรวม
วางดาว 8 ดวงเป็นวงแหวนตายตัว เริ่มที่ดาวประจำวันเกิดแล้วไล่ภูมิ 8 ภูมิตามลำดับ ดาวที่ตกภูมิ "กาลกิณี" คือดาวที่ต้องเลี่ยง (ทั้งอักษรในชื่อและสี) ทักษาปรับมาจากกรอบมหาทักษา

## ข้อมูลนำเข้า
- **วันเกิด** → ดาววันเกิด (ต้องนับวันแบบไทย ดู [thai-birth-day.md](thai-birth-day.md))
- เวลาเกิด (ไม่บังคับ) → แยกพุธกลางวัน (๔) กับพุธกลางคืน (ราหู ๘) และกรณีเกิดก่อนพระอาทิตย์ขึ้น
- เกิดวันพุธแต่ไม่มีเวลา → **แสดงทั้งสองแบบ**

## อัลกอริทึม
```js
const RING = [1, 2, 3, 4, 7, 5, 8, 6];   // อา จ อ พ ส พฤ รา ศ
const BHUMI = ['บริวาร','อายุ','เดช','ศรี','มูละ','อุตสาหะ','มนตรี','กาลกิณี'];
// p = ดาววันเกิด (พุธกลางคืน = 8)
bhumi[k] = RING[(RING.indexOf(p) + k) % 8];   // k = 0..7
```

### ความหมายภูมิ
บริวาร = คนรอบตัว ผู้ใต้บังคับบัญชา · อายุ = สุขภาพ อารมณ์ · เดช = อำนาจ เกียรติยศ · ศรี = เสน่ห์ ความรัก สิริมงคล · มูละ = ทรัพย์สิน รากฐาน · อุตสาหะ = ความขยัน · มนตรี = ผู้อุปถัมภ์ · กาลกิณี = ศัตรู อุปสรรค รายจ่าย

### สีมงคล/กาลกิณี [ยังไม่ยืนยัน: แต่ละเว็บใช้ต่างกัน]
สีของภูมิ = สีของดาวที่ครองภูมินั้น (อาทิตย์ แดง, จันทร์ เหลือง/ครีม, อังคาร ชมพู, พุธ เขียว, พฤหัส ส้ม, ศุกร์ ฟ้า, เสาร์ ม่วง/ดำ, ราหู เทา/ดำ) สีกาลกิณี = สีของดาวกาลกิณี เช่น คนเกิดวันอาทิตย์เลี่ยงสีฟ้า (ศุกร์)
ต้องติดป้ายธรรมเนียมใต้ผล

### อักษรประจำดาว [ยังไม่ยืนยัน — ใช้ตั้งชื่อ แต่เว็บนี้ไม่ขอชื่อ]
อาทิตย์ = สระ · จันทร์ = ก–ง · อังคาร = จ–ญ · พุธ = ฎ–ณ · เสาร์ = ด–น · พฤหัส = บ–ม · ราหู = ย ร ล ว · ศุกร์ = ศ–ฮ
ใช้แสดงเป็นข้อมูลความรู้ได้เท่านั้น ห้ามขอชื่อผู้ใช้มาคำนวณ

## ค่าตรวจ (unit test)
- วันจันทร์: กาลกิณี = อาทิตย์ (ตรงกับที่ทักษาปกรณ์อธิบายว่าคนเกิดวันจันทร์เลี่ยงสระ)
- พุธกลางคืน: บริวาร = ราหู, อายุ = ศุกร์, …, กาลกิณี = พฤหัส
- ทักษาจร เริ่มที่อังคาร: กาลกิณี = จันทร์ (ตามตัวอย่างดวงเมืองรัตนโกสินทร์ของมติชน)

## ยังไม่ยืนยัน
- [ ] การผูกอักษรกับดาว
- [ ] ทิศของดาว (ยืนยันแล้วเฉพาะอาทิตย์ = อีสาน, อังคาร = อาคเนย์) ค่าที่อนุมาน: จันทร์ บูรพา, พุธ ทักษิณ, เสาร์ หรดี, พฤหัส ประจิม, ราหู พายัพ, ศุกร์ อุดร
- [ ] ตารางสีของภูมิ
