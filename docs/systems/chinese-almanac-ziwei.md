# ปฏิทินจีนวันนี้ (宜忌 / 冲煞 / 建除) · 紫微斗數

> หมวด: จีน · สถานะ: ปฏิทินจีนวันนี้ = **วิดเจ็ตรายวัน (ไม่ใช้ข้อมูลเกิด)**, 紫微斗數 = **Phase 2**
> กลับไปที่ [CLAUDE.md](../../CLAUDE.md)

## ปฏิทินจีนวันนี้

### ภาพรวม
ข้อมูลรายวันจาก `lunar-javascript` ได้มาเกือบฟรี: วันจันทรคติจีน, 干支 ของวัน, 宜 (ควรทำ) / 忌 (ไม่ควรทำ), 冲煞 (วันนี้ชงกับปีอะไร ทิศอะไร), 建除十二值星, 吉神方位, 納音, 二十八宿, 彭祖百忌 เหมาะเป็นเครื่องมือรายวันที่สร้างผู้ใช้ประจำ (แบบที่ myhora ทำ)

### ข้อมูลนำเข้า
- วันนี้ตาม Asia/Bangkok เท่านั้น (ไม่ต้องใช้ข้อมูลเกิด)
- ถ้าผู้ใช้กรอกวันเกิดไว้ → ไฮไลต์ว่าวันนี้ "ชง" กับปีเกิดหรือไม่ (คำนวณ client-side)

### ธรรมเนียม
- ขอบวันตามไลบรารี (เขตเวลาจีน UTC+8) ต้องประกาศไว้ใต้ผล

### การใช้งาน
```js
// ชื่อเมธอดยังไม่ยืนยัน — ตรวจจากซอร์สใน npm
const lunar = Solar.fromYmd(y, m, d).getLunar();
lunar.toFullString();   // ตัวอย่างใน README: 1986-05-29 → 农历丙寅年四月廿一
```

### แนวทาง GUI
- การ์ดเล็กโทนแดงชาด + ทอง แปล 宜/忌 เป็นภาษาไทยสั้นๆ
- ห้ามใช้ 忌 หรือ 冲煞 เป็นข้อความขู่
