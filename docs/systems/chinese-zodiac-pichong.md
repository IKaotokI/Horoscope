## ภาพรวม
ปีนักษัตรสำหรับดวงจีนเปลี่ยนที่**ลิบชุน 立春** ไม่ใช่ตรุษจีน และไม่ใช่ขอบปีนักษัตรแบบไทย ปีชงแบบที่สื่อไทยเผยแพร่ไม่ตรงกับ 犯太岁 แบบจีนคลาสสิก

## ข้อมูลนำเข้า
- **วันเกิด** (เวลาช่วยได้ถ้าเกิดวันลิบชุนพอดี)
- ปีปัจจุบัน (สำหรับปีชง)

## ธรรมเนียมและค่าตั้งต้น
| ประเด็น | ค่าตั้งต้น | ตัวเลือก |
|---|---|---|
| ขอบปี | **ลิบชุน (~4 ก.พ., λ☉ = 315°)** เวลาจาก lunar-javascript | "ตรุษจีน" |
| เกิดก่อนลิบชุน/ตรุษจีน | แสดงสัตว์ทั้งสองตัวพร้อมคำอธิบาย | – |
| ปีชง | แบบไทย (กลุ่ม 4) [อนุมาน] | แสดง 破/害/刑 เป็น "ชงอ้อม" |

ปี 2569: ลิบชุน 4 ก.พ., ตรุษจีน 17 ก.พ.

## อัลกอริทึม
```
Y      = ปี ค.ศ. − (เกิดก่อนลิบชุนของปีนั้น ? 1 : 0)
stem   = (Y − 4) mod 10      // 0 = 甲
branch = (Y − 4) mod 12      // 0 = 子 (ชวด)
หยาง/หยิน: stem คู่ = หยาง, คี่ = หยิน
```
ธาตุของก้าน: 甲乙 ไม้ · 丙丁 ไฟ · 戊己 ดิน · 庚辛 ทอง · 壬癸 น้ำ
ทางลัดจากเลขท้าย ค.ศ.: 0–1 ทอง, 2–3 น้ำ, 4–5 ไม้, 6–7 ไฟ, 8–9 ดิน

### ปีชงแบบไทย [อนุมานจากรายการที่สื่อเผยแพร่]
```
y = branch ของปีปัจจุบัน
ชงตรง    = (y + 6) mod 12
ชงตัวเอง = y
ชงร่วม   = สมาชิกที่เหลือในกลุ่ม y mod 3   // 子午卯酉 / 寅申巳亥 / 辰戌丑未
```
ป้ายยังไม่ตรงกัน: ฐานเศรษฐกิจเรียกมะเมียปี 2569 ว่า "ชงตัวเอง" บางแหล่งเรียก "ชงร่วม" ไทยรัฐจัดอันดับ 1–12 โดยไม่มีเปอร์เซ็นต์

### คู่สัมพันธ์ [std]
| ความสัมพันธ์ | สูตร | คู่ |
|---|---|---|
| 六冲 ชง | `(b+6)%12` | 子午 丑未 寅申 卯酉 辰戌 巳亥 |
| 三合 สามประสาน | `(b±4)%12` | 申子辰 น้ำ, 寅午戌 ไฟ, 亥卯未 ไม้, 巳酉丑 ทอง |
| 六合 คู่มิตร | `(13−b)%12` | 子丑 寅亥 卯戌 辰酉 巳申 午未 |
| 六害 | `(19−b)%12` | 子未 丑午 寅巳 卯辰 申亥 酉戌 |
| 相破 | ตาราง | 子酉 午卯 寅亥 巳申 辰丑 戌未 |
| 相刑 | ตาราง | 寅巳申, 丑戌未, 子卯, ตัวเอง 辰午酉亥 |

ชื่อไทย: ชวด (หนู) ฉลู (วัว) ขาล (เสือ) เถาะ (กระต่าย) มะโรง (มังกร/งูใหญ่/นาค) มะเส็ง (งูเล็ก) มะเมีย มะแม วอก ระกา จอ กุน (หมู)
