# ฤกษ์ 27 (นักษัตรฤกษ์)

> หมวด: ไทย/อินเดีย · สถานะ: **ปลดล็อกเมื่อกรอกเวลา** (ไม่มีเวลาอาจได้ 2 ค่า)
> กลับไปที่ [CLAUDE.md](../../CLAUDE.md) · พึ่งพา: [ราศีไทย (Lahiri)](thai-rasi-lagna.md)

## ภาพรวม
แบ่งสุริยวิถีแบบนิรายนะเป็น 27 ส่วนเท่ากัน ส่วนละ 13°20′ แต่ละส่วนมี 4 บาท (pada) บาทละ 3°20′ รวม 108 บาท ฤกษ์เกิดดูจากตำแหน่งดวงจันทร์

## ข้อมูลนำเข้า
- **วันเกิด** (บังคับ)
- **เวลาเกิด** (แนะนำ) — ดวงจันทร์เดินราว 13°/วัน ≈ 1 ฤกษ์ต่อวัน

## ธรรมเนียมและค่าตั้งต้น
| ประเด็น | ค่าตั้งต้น |
|---|---|
| ayanamsa | Lahiri (เหมือน [ราศีไทย](thai-rasi-lagna.md)) |
| ไม่มีเวลา | คำนวณที่ 00:00 และ 23:59 ถ้าได้ต่างกัน → แสดงทั้ง 2 ฤกษ์พร้อมหมายเหตุ |

## อัลกอริทึม
```
λ_sid = norm360(λ_moon_trop − ayanamsa)
n     = floor(λ_sid / 13.3333) + 1                 // 1..27
pada  = floor((λ_sid mod 13.3333) / 3.3333) + 1    // 1..4
```

## ค่าตรวจ (unit test)
- λ_sid = 0° → ฤกษ์ 1 บาท 1; 13.34° → ฤกษ์ 2; 359.9° → ฤกษ์ 27 บาท 4
- เทียบฤกษ์จันทร์รายวันกับปฏิทินโหราศาสตร์ลาหิรีของ myhora

## ยังไม่ยืนยัน
- [ ] ชื่อฤกษ์ 27 ในภาษาไทย (สะกดต่างกันในแต่ละตำรา)
- [ ] การจัด 9 หมู่ฤกษ์
- [ ] วิธีที่ปฏิทินโหราศาสตร์ไทยคำนวณฤกษ์จันทร์

## แนวทาง GUI
- วงนอก 27 ช่องรอบวงล้อ 12 ราศี (ช่องละ 13°20′) ไฮไลต์ช่องที่ดวงจันทร์อยู่

## ประวัติย่อ
อาถรรพเวทระบุ 28 กลุ่มดาว (เริ่มที่กฤติกา) ไตตติรียสัมหิตาและศตปถพราหมณ์ระบุ 27 สูรยสิทธานต์ให้พิกัดของทั้ง 27 ฤกษ์
