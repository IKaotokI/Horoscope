# ราศีไทย (นิรายนะ) · ลัคนา · 12 ภพ

> หมวด: ไทย · สถานะ: ราศีเกิด = **MVP**, ลัคนา/ภพ = **ปลดล็อกเมื่อกรอกเวลา + จังหวัด**, สุริยยาตร์ = **Phase 2**
> กลับไปที่ [CLAUDE.md](../../CLAUDE.md)

## ภาพรวม
ราศีเกิดแบบไทยคือราศีที่ดวงอาทิตย์สถิตอยู่ในจักรราศีแบบ **นิรายนะ (sidereal)** ไม่ใช่ราศีแบบนิตยสารที่ใช้วันที่แบบตะวันตก ดวงชะตาไทยมี 12 ช่องตาม 12 ราศี เขียนดาวเป็นเลขไทย และเขียนลัคนาว่า "ลั"

โหราศาสตร์ไทยมีสองสำนักคำนวณ
- **คัมภีร์สุริยยาตร์**: ใช้มาตั้งแต่สุโขทัย กรมโหรหลวงใช้ทำปฏิทิน ไม่ใช้ ayanamsa จริง แต่ใช้การแก้แบบวัฏจักร "0–27 องศาในรอบ 1800 ปี"
- **นิรายนะ ลาหิรี**: ตรงกับท้องฟ้าจริงตามดาราศาสตร์สมัยใหม่

สองแบบต่างกันได้: **ลัคนา ±1 ราศี**, ฤกษ์ลัคนา 4–17°, **พุธ/ศุกร์ 4–15°** (อาจเปลี่ยนราศี) แหล่งไทยสรุปว่า "ไม่มีใครถูกหรือผิด"

## อัลกอริทึม
```
λ_trop  = ลองจิจูดสุริยวิถีแบบ tropical จาก astronomy-engine
ayan    = Lahiri(วันที่)            // ≈ 23.84° ที่ J2000, ≈ 24.2° ในปี 2026
λ_sid   = norm360(λ_trop − ayan)
rasi    = floor(λ_sid / 30)         // 0 = เมษ … 11 = มีน
```
- สูตรประมาณ `ayan ≈ 23.85° + (year−2000) × 50.29″/3600` **[ยังไม่ยืนยัน]** ต้องเทียบกับตาราง Lahiri อ้างอิงก่อนใช้
- ลัคนา (ASC) ใช้สูตรเดียวกับฝั่งสากล `atan2(cos RAMC, −(sin RAMC·cos ε + tan φ·sin ε))` แล้วลบ ayanamsa (ดู [western-zodiac.md](western-zodiac.md))
- `circular-natal-horoscope-js` ให้ภพและ ASC/MC ได้ แต่**ไม่ระบุ ayanamsa** ให้ใช้โหมด tropical แล้วลบ Lahiri เอง
- วันที่ราศีไทยเปลี่ยน (~13–17 ทุกเดือน) **ห้าม hard-code** ให้คำนวณจาก ephemeris เสมอ

## ค่าตรวจ (unit test)
- ดวงอาทิตย์เข้าเมษแบบนิรายนะราว 14 เม.ย. (≈ 21 มี.ค. + ~24 วัน) — ตรวจด้วย ephemeris ไม่ใช่ตัวเลขตายตัว
- เทียบตำแหน่งดาวกับ ephemeris ลาหิรีของ myhora ในวันสุ่ม

## แนวทาง GUI
- ดวงชะตา 12 ช่องเป็น SVG ใช้เลขไทย ๑–๙/๐ ช่องลัคนาเป็นสีทอง มี toggle มุมมองวงกลม

## ประวัติย่อ
คัมภีร์สุริยยาตร์ใช้มาตั้งแต่สุโขทัย กรมโหรหลวงใช้คู่กับคัมภีร์มานัตต์ทำปฏิทินโหรและปฏิทินจันทรคติ โหรไทยเคยผูกดวงให้มกุฎราชกุมารรัสเซียตอนเสด็จเยือนสยามปี 1891
