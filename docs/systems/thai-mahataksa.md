## ภาพรวม
แต่ละดาว "เสวยอายุ" เป็นจำนวนปีเท่ากับกำลังวัน เดินตามวงแหวนทักษาจากดาววันเกิด ครบรอบที่ 108 ปี

## ข้อมูลนำเข้า
- **วันเกิด** → ดาววันเกิด + อายุปัจจุบัน
- วันนี้ (Asia/Bangkok)

## ธรรมเนียมและค่าตั้งต้น
| ประเด็น | ค่าตั้งต้น | ตัวเลือก/สำนักอื่น |
|---|---|---|
| ช่วงแรก | **นับเต็มช่วงตั้งแต่เกิด** | บางสำนักเริ่มด้วยเศษที่เหลือของช่วงแรก (แบบ Vimshottari) |
| อายุ | ปีเต็มนับจากวันเกิด (float ได้) | บางสำนักนับอายุเริ่มที่ 1 |
| จันทร์ | 15 ปี | บางตำรา 18 (จะทำให้รวมไม่เท่า 108) |

## อัลกอริทึม
```js
const RING  = [1, 2, 3, 4, 7, 5, 8, 6];
const YEARS = {1:6, 2:15, 3:8, 4:17, 7:10, 5:19, 8:12, 6:21};   // รวม 108

function dasa(p, age) {
  const a = age % 108;
  let i = RING.indexOf(p), cum = 0;
  for (let k = 0; k < 8; k++) {
    const q = RING[(i + k) % 8];
    if (cum + YEARS[q] > a) return { planet: q, from: cum, to: cum + YEARS[q] };
    cum += YEARS[q];
  }
}
```
**อนุทักษา [ยังไม่ยืนยัน]**: แบ่งช่วงใหญ่ออกเป็น 8 ช่วงย่อยตามวงแหวน เริ่มจากดาวช่วงใหญ่ ยาว `major × minor / 108` ปี
