# Kua 命卦 · 八宅 (ฮวงจุ้ยแปดทิศ)

> หมวด: จีน · สถานะ: **ปลดล็อกเมื่อกรอกเพศกำเนิด**
> กลับไปที่ [CLAUDE.md](../../CLAUDE.md) · เกี่ยวข้อง: [12 นักษัตร (ขอบปีลิบชุน)](chinese-zodiac-pichong.md)

## ภาพรวม
เลข Kua บอกกลุ่ม (ตะวันออก/ตะวันตก) และทิศมงคล 4 ทิศ ทิศอัปมงคล 4 ทิศ เป็นศาสตร์เดียวที่**ขาดเพศไม่ได้**

## ข้อมูลนำเข้า
- **วันเกิด** → ปีตามลิบชุน
- **เพศกำเนิด** (ไม่บังคับในฟอร์ม) — ไม่กรอก → ซ่อนผลหรือแสดงทั้งชายและหญิง

## อัลกอริทึม
```js
const r = lichunYear % 9;
let k = male ? (11 - r) % 9 : (r + 4) % 9;
if (k === 0) k = 9;
if (k === 5) k = male ? 2 : 8;     // 男寄坤 / 女寄艮
```
สูตรนี้ไม่ขึ้นกับศตวรรษ (เว็บที่สลับค่าคงที่ตอนปี 2000 ได้ผลเพี้ยนสำหรับผู้หญิงที่เกิดหลังปี 2000)

- **กลุ่มตะวันออก**: 1 坎, 3 震, 4 巽, 9 离
- **กลุ่มตะวันตก**: 2 坤, 6 乾, 7 兑, 8 艮
- ดาวมงคล: 生气, 天医, 延年, 伏位 · ดาวอัปมงคล: 绝命, 五鬼, 祸害, 六煞
