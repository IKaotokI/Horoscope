# ไบโอริทึม (Biorhythm)

> หมวด: สากล · สถานะ: **MVP (ส่วนเสริม)** · ต้องติดป้าย **pseudoscience / เพื่อความบันเทิง**
> กลับไปที่ [CLAUDE.md](../../CLAUDE.md)

## ภาพรวม
คลื่นไซน์ 3 เส้น คาบ 23 วัน (ร่างกาย), 28 วัน (อารมณ์), 33 วัน (สติปัญญา) นับจากวันเกิด งานวิจัยหลายชิ้นหักล้างแล้ว แต่ทำกราฟได้สวยและคำนวณง่าย

## ข้อมูลนำเข้า
- **วันเกิด**, วันนี้ตาม Asia/Bangkok

## ธรรมเนียมและค่าตั้งต้น
| ประเด็น | ค่าตั้งต้น |
|---|---|
| t | **จำนวนวันเต็มตามปฏิทิน** ใน Asia/Bangkok (ใช้ JDN ต่างกัน เลี่ยง off-by-one จาก UTC) |
| รอบ | 3 รอบคลาสสิกเท่านั้น (ไม่ใส่ 38/43/53) |

## อัลกอริทึม
```js
t = JDN(today) - JDN(birth);
physical     = Math.sin(2 * Math.PI * t / 23);
emotional    = Math.sin(2 * Math.PI * t / 28);
intellectual = Math.sin(2 * Math.PI * t / 33);
critical(p)  = Math.sign(sin(t)) !== Math.sign(sin(t + 1));   // วันตัดศูนย์
```
รอบ 23 กับ 28 มาบรรจบทุก 644 วัน ทั้งสามรอบทุก 21,252 วัน (~58.18 ปี)

## ค่าตรวจ (unit test)
- เกิด 29 พ.ย. 1990 ดูวันที่ 11 ต.ค. 2026 → t = **13,100** → ร่างกาย **−0.398**, อารมณ์ **−0.782**, สติปัญญา **−0.189**
- t = 0 → ทั้งสามค่า = 0

## แนวทาง GUI
- กราฟคลื่น 3 สีรอบหมุด "วันนี้" ±15 วัน
- ป้าย "เพื่อความบันเทิง ไม่มีหลักฐานทางวิทยาศาสตร์รองรับ" อยู่ใกล้กราฟ ไม่ใช่ซ่อนท้ายหน้า
- ห้ามใช้วัน critical เป็นคำเตือนเรื่องสุขภาพหรืออุบัติเหตุ

## ประวัติย่อ
Wilhelm Fliess (แพทย์ชาวเบอร์ลิน เพื่อนของฟรอยด์) เสนอรอบ 23/28 วันปลายศตวรรษที่ 19, Hermann Swoboda ได้ข้อสรุปคล้ายกันในปี 1904, Alfred Teltscher เพิ่มรอบ 33 วัน, Bernard Gittelson ทำให้เป็นแฟชั่นในทศวรรษ 1970 (มีตู้เกมและเครื่องคิดเลขไบโอริทึม) งานวิจัยของ Persinger (1978), James (1984) และบทวิจารณ์ของ Hines (1998) ไม่พบผล
