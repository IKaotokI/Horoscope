# เลขศาสตร์จากวันเกิด (Life Path · Birthday · Personal Year)

> หมวด: สากล · สถานะ: **MVP**
> กลับไปที่ [CLAUDE.md](../../CLAUDE.md)

## ภาพรวม
ลดหลักวันเกิดให้เหลือ 1–9 โดยเก็บเลขมาสเตอร์ 11/22/33 ไว้ แต่ละวิธีลดให้ผลต่างกันจริง ต้องเลือกวิธีเดียว ประกาศไว้ และแสดงแบบเต็มคู่แบบลด

หมายเหตุตลาดไทย: เลขศาสตร์ในไทยผูกกับชื่อและเบอร์โทรเป็นหลัก ซึ่งเว็บนี้**ไม่ขอ**ตามกฎความเป็นส่วนตัว เลขศาสตร์จากวันเกิดจึงเป็นตลาดเฉพาะกลุ่ม

## ข้อมูลนำเข้า
- **วันเกิด**, ปีปัจจุบัน (Personal Year)

## ธรรมเนียมและค่าตั้งต้น
| ประเด็น | ค่าตั้งต้น | สำนักอื่น |
|---|---|---|
| Life Path | **ลดทีละส่วน** r(M)+r(D)+r(Y) แล้ว r() อีกครั้ง | รวมเลขทุกหลัก, บวกเลขทั้งก้อน |
| การแสดงผล | "33/6" | – |
| Personal Year | เปลี่ยนวันที่ **1 ม.ค.** | เปลี่ยนวันเกิด |

## อัลกอริทึม
```js
const MASTER = [11, 22, 33];
const r = n => { while (n > 9 && !MASTER.includes(n)) n = digitSum(n); return n; };

lifePath     = r(r(M) + r(D) + r(Y));
birthday     = r(D);                          // 1–9, 11, 22
personalYear = r(r(M) + r(D) + r(currentYear));
personalMonth = r(personalYear + currentMonth);
personalDay   = r(personalMonth + currentDay);
```

## ค่าตรวจ (unit test)
| วันเกิด | ลดทีละส่วน (ค่าตั้งต้น) | บวกเลขทั้งก้อน |
|---|---|---|
| 6 พ.ค. 1984 | **33** (5 + 6 + 22) | 1995 → 6 |
| 29 พ.ย. 1990 | **5** | 2030 → 5 |
| 24 ต.ค. 1966 | **11** | 2000 → 2 |

## ประวัติย่อ
gematria/isopsephy เป็นของโบราณ (จารึกของซาร์กอนที่ 2 ศตวรรษที่ 8 ก่อน ค.ศ.) อริสโตเติลโยง isopsephy กับสำนักพีทาโกรัส แต่คำว่า "numerology" เพิ่งปรากฏในภาษาอังกฤษราวปี 1907 การโยงเลขศาสตร์สมัยใหม่กับพีทาโกรัสเป็นการอ้างย้อนหลัง
