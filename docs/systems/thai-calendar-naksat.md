# ปฏิทินไทย · จันทรคติ · นักษัตรไทย

> หมวด: ไทย · สถานะ: **MVP** (เป็นฐานของเลข 7 ตัวและปีนักษัตรไทย)
> กลับไปที่ [CLAUDE.md](../../CLAUDE.md) · เกี่ยวข้อง: [12 นักษัตรจีน/ปีชง](chinese-zodiac-pichong.md) (คนละขอบปี)

## ภาพรวม
แปลงปี พ.ศ./จ.ศ. หาวันจันทรคติ (ข้างขึ้น/แรม เดือนไทย) และหาปีนักษัตรแบบไทย **จันทรคติห้ามคำนวณเอง** ให้ใช้ไลบรารีเท่านั้น

## ข้อมูลนำเข้า
- **วันเกิด**

## ธรรมเนียมและค่าตั้งต้น
| ประเด็น | ค่าตั้งต้น | ตัวเลือก |
|---|---|---|
| ขอบปีนักษัตรไทย | **ขึ้น 1 ค่ำ เดือน 5** (ตามศิลปวัฒนธรรม) | "สงกรานต์", "1 ม.ค." |
| คำเตือน | เกิดระหว่าง 1 ม.ค. – กลาง เม.ย. → ขึ้นคำเตือนและบอกว่าใช้ขอบไหน | – |

หลักฐานขัดกัน: Wikipedia บอกเปลี่ยนที่สงกรานต์ แต่ศิลปวัฒนธรรมยืนยันว่าตามประเพณีเปลี่ยนที่ขึ้น 1 ค่ำ เดือน 5 และ "สงกรานต์ไม่ใช่วันเปลี่ยนนักษัตร" นักษัตรกับ จ.ศ. จึงอาจเปลี่ยนคนละวัน (เช่น ปี 2566: นักษัตรเปลี่ยน 22 มี.ค., จ.ศ. เปลี่ยน 16 เม.ย. — จากบล็อก ต้องตรวจ)

## อัลกอริทึม
```
พ.ศ. = ค.ศ. + 543
จ.ศ. = ค.ศ. − 638   (หลังเถลิงศก/สงกรานต์), ค.ศ. − 639 ก่อนหน้านั้น   // epoch 22 มี.ค. 638
Y = ปี ค.ศ. หลังปรับตามขอบปีที่เลือก
naksat(ชวด = 1) = ((Y − 4) mod 12) + 1
```
ชื่อ: ชวด ฉลู ขาล เถาะ มะโรง มะเส็ง มะเมีย มะแม วอก ระกา จอ กุน (ไทยใช้นาคแทนมังกร)

### จันทรคติ
- ปีจันทรคติยาว 354 (ปกติ) / 355 (อธิกวาร: เพิ่มวันในเดือน 7) / 384 (อธิกมาส: เดือน 8 ซ้ำ "8/8")
- เดือนคี่ 29 วัน (ขาด) เดือนคู่ 30 วัน (เต็ม) ข้างขึ้น 15 วันเสมอ ข้างแรม 14/15
- เดือนอ้าย (1) มักเริ่มในเดือน ธ.ค. และ**ไม่ใช่**วันขึ้นปีใหม่
- ไลบรารี: **pythaidate** (Python, MIT) — ฝั่ง JS ต้อง port หรือทำตารางล่วงหน้า; **thai_lunar** (Dart, ใช้จำนวนเต็มเลี่ยง float drift, ไลเซนส์ยังไม่ตรวจ)
- ปฏิทินหลวงใช้กฎสุริยยาตร์ บางครั้งต่างจากเดือนดับทางดาราศาสตร์ 1 วัน → ต้องตรวจกับปฏิทินหลวง

### สูตรสุริยยาตร์ที่จำมา [ยังไม่ยืนยัน — ห้ามใช้จนกว่าจะเทียบกับซอร์ส pythaidate]
```
horakhun    = floor((CS*292207 + 373)/800) + 1
kammacubala = 800 − ((CS*292207 + 373) mod 800)
uccabala    = (horakhun + 2611) mod 3232
avoman      = (11*horakhun + 650) mod 692
masaken     = floor((horakhun + floor((11*horakhun + 650)/692)) / 30)
tithi       = (horakhun + floor((11*horakhun + 650)/692)) mod 30
```
